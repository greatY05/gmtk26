game jam for GTMK 2026's theme: COUNT DOWN

the game is a collectathon platformer where you have to pick up an objective item in time intervals of 15 seconds
the main focus was flashing out a character controls, camera system, and taking a real shot at serious 3d environment building

therefor the game is less technical, and more fine tuned with the simple aspects it has, with most time spent on the previously mentioned controls and camera.

the environment uses stochastic filler with noise map to blend a single texture into a decent looking repeating texture that covers literally everything in the game

overall it was a pretty great game jam project, i will likely not continue work on it past the jam but it scratched the itch of trying some serious 3d game
